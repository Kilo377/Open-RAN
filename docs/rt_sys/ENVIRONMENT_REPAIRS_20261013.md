# 2026-10-13：系统级 O-RAN 环境修复与验收

目标是先建立可信的 Sionna RT + NR 参考反馈 + SYS 多小区闭环，再开展算法实验。A1/E2 保持语义生命周期仿真，不接入真实协议栈。

## 当前仿真边界

对功率、波束、休眠、资源调度、关联和业务 QoS 等系统级问题，不需要每个时隙执行完整 OFDM 干扰波形及实际导频信道估计。RT 信道与联合多小区 RZF/LMMSE 计算给出逐资源 SINR，再通过实际 NR 编解码参考反馈产生 ACK/NACK，是当前采用的系统级建模路线。Sionna 的 [PHY abstraction 教程](https://nvlabs.github.io/sionna/v2.2.0/sys/tutorials/notebooks/PHY_Abstraction.html)也将逐资源 SINR、有效 SINR、传输能力和错误概率用于系统级抽象。

当前 NR 参考模式在后均衡等效高斯资源上执行 CRC/LDPC/QAM；不把它称作完整 OFDM 波形仿真。默认理想 CSI；可选 NMSE 扰动不是实际导频估计。若后续研究 CSI 上报、导频污染、信道估计、非高斯干扰、同步或接收机实现，需要加入对应波形链路及独立校准。`full_phy_calibrated` 继续为 false。

## 五项修复

1. **控制观测**：服务链路 RSRP 和参考 SINR 使用绝对 RT CFR、实际天线权重及功率，不再叠加经验路径损耗、阴影、快衰落或波束增益。参考 SINR 明确采用邻小区全带参考发射假设，数据 SINR 使用已执行 grant 的后 LMMSE 结果，两者不混称。施加可重放的测量噪声、EWMA 及既有观测延迟；切换后重置服务链路滤波。波束 xApp 的次级 SINR 也读取测量值，未调度时标记参考假设，不直接泄露 PHY 真值。诊断 trace 仍保存实际数据链路结果。
2. **业务时延**：新增逐 LC FIFO 分组账本，记录到达、部分交付、完成时延、超期和队列溢出。队头时延来自最早未完成分组的到达时间，并与延迟队列报告一起进入控制观测，不再使用报告年龄代替。原字节业务模型按配置分组大小切分，最后一块可以更短；这是可追踪的到达单位，不宣称实现完整 IP/RLC 协议。满队列按整个到达单位丢弃。超期分组记录后仍排队，不会静默删除 HARQ 所拥有的数据。初始积压是 slot 0 到达的初始条件，会贡献真实超期。
3. **HARQ 生命周期**：空预留清理与正载荷失败分开统计；零 TB 不进入 CRC BLER 样本。重传零容量时保留原待重传载荷，仅清理空预留。每进程保存实际 MCS/表，重传保持固定，不静默降级到另一 MCS；队列、ACK、容量限制和正载荷 flush 分别记账。参考模式仍是独立 RV0 码块尝试，尚未实现同码字 IR/Chase 软合并，并拒绝配置抽象 Chase 为参考波形合并。
4. **链路自适应**：默认 AMC 与独立 BLER 探针各 64 次，AMC 按 Wilson 95% 上界筛选，选择、BLER 估计和实际 TB 使用独立、按种子/slot/UE 索引的随机流。新增表 3 和单码块 BG2 RV0 循环重复低码率支持，复用 Sionna 母码、CRC、扰码和 BP 解码。测试检查母码前缀、校验矩阵、标量/批处理及高低 SNR 解码。多码块重复仍明确不支持；没有可执行编码时输出明确的零 TB，而非近似回退。所有候选未满足目标时明确标记 `amc_selection_target_met=false`，不宣称有限探针能保证每条链路 BLER，更不保证 URLLC 尾概率。快速 EESM 仍未校准通过，生产门禁继续关闭。
5. **覆盖和固定基线**：入口默认 `--control-mode baseline`，关闭 rApp/xApp 和学习，初始关联选择 RT 参考增益最强小区（此次基线各小区功率相同），后续继续用带延迟测量的关联生命周期。原控制路径可通过 `orchestrated` 显式启用。新增逐 UE/slot 字节守恒、交付/ACK/TB/队列一致性、资源/功率预算和正载荷 HARQ flush 审计。保留算法前的覆盖验收，不将积压直接归因于算法。
